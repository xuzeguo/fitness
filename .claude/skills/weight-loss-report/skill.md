# 减重报告生成器

自动分析健身数据并生成减重进度报告。

## 功能

1. **数据对比**
   - 当前 vs 上次测量
   - 当前 vs 一周前
   - 当前 vs 一个月前
   - 当前 vs 目标值

2. **趋势分析**
   - 体重变化趋势（kg/周）
   - 体脂率变化趋势（%/周）
   - 围度变化（腰围、臀围等关键部位）

3. **进度评估**
   - 距离目标还有多远
   - 按当前速度预计到达时间
   - 是否在健康减脂范围内（0.5-1kg/周）

4. **建议与提醒**
   - 训练强度建议
   - 饮食调整提示
   - 休息恢复建议

## 使用方式

```bash
/weight-loss-report
```

报告会自动保存到 `docs/weight-loss-report-YYYY-MM-DD.md`

## 报告示例

```markdown
# 减重进度报告 2026-07-06

## 📊 当前数据
- 体重：82.4 kg
- 体脂率：24.2%
- 腰围：88 cm
- 臀围：99 cm

## 📈 变化对比
### 近一周（07-06 vs 06-29）
- 体重：-0.7 kg ⬇️
- 体脂率：-0.3% ⬇️
- 腰围：持平

### 近一月（07-06 vs 06-06）
- 体重：-3.2 kg ⬇️
- 体脂率：-1.2% ⬇️

## 🎯 目标进度
- 目标体重：75 kg
- 剩余：7.4 kg
- 完成度：68%
- 预计到达：约 15 周后（2026-10-20）

## 💡 评估与建议
✅ 减重速度健康（0.8 kg/周）
✅ 体脂下降稳定
⚠️ 建议加强核心训练
```
