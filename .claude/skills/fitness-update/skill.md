# 健身数据更新助手

这个 skill 帮助你快速更新三类健身数据：

## 1. 训练记录更新
- 文件：`public/training-log.csv`
- 包含：日期、运动时长、各种训练动作（重量×次数×组数）、有氧记录

## 2. 体重体脂更新
- 文件：`public/body-metrics.csv`
- 包含：日期、体重（kg）、体脂率（%）

## 3. 围度测量更新
- 文件：`public/girth.csv`
- 包含：日期（YYYY-MM-DD）、脖子、胸围、臂围、腰围、臀围、大腿根部（单位：cm）

## 使用方式

直接告诉我你要更新什么数据，例如：
- "今天训练了背部，高位下拉30kg×15×4"
- "今天体重82.3kg，体脂率24.1%"
- "今天测量围度：腰围88cm，臀围99cm"

我会：
1. 读取当前数据文件
2. 添加新记录（自动填充日期为今天）
3. 更新 CSV 文件
4. 重新生成 `public/data.json`（用于前端展示）

## 注意事项

- 日期格式：`MM-DD`（如 07-06）
- 训练动作格式：`重量kg×次数×组数`（如 30kg×15×4）
- 围度日期格式：`YYYY-MM-DD`（如 2026-07-06）
- 自动按日期排序
- 如果当天已有记录，会询问是否覆盖或追加
